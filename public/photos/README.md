# Photos

Put birthday and memory photos here.

Use them in the content editor with paths like:

```text
/photos/first-date.webp
/photos/favourite-photo.jpg
```

Prefer `.webp` or `.avif` for smaller mobile downloads. Keep filenames simple: lowercase letters, numbers, and hyphens.

## Final birthday photo

The final greeting uses `/photos/final-placeholder.svg` until you add your own photo.
Put your replacement in this folder, for example `public/photos/final-photo.jpg`.
Then open `/admin/content`, set **Final photo** to `/photos/final-photo.jpg`, and save.
Use the actual filename and extension; omit `public` from the image URL.
If a configured final image cannot load, the rose placeholder appears automatically.
